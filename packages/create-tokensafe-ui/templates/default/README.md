# TokenSafe UI Starter App

A modern, deterministic frontend application built with **TokenSafe UI** and implementing **OUMV: The Universal Agent-UI Protocol**.

## Getting Started

```bash
# Install dependencies
pnpm install

# Start local dev server
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## AI Agent Integration

This project is pre-configured with `.mcp.json`. When you open this folder with Claude Code, Cursor, or Antigravity, the AI agent can autonomously:
- **Observe** the live UI via structured semantic snapshots (L0–L4).
- **Understand** the dynamic reactive dependency graph and causality traces.
- **Mutate** components safely with OCC versioning and atomic rollback.
- **Verify** state changes and user interactions in low single-digit milliseconds.
