# @tokensafe/benchmark (AUB / AUI-Bench)

> **Agent Usability Benchmark (AUB): Comparative Autonomous Agent Evaluation Framework (React vs. TokenSafe UI).**

This package implements the **Agent Usability Benchmark (AUB)** measuring the development velocity, error resilience, and functional yield per token of AI coding agents.

---

## Quickstart

```bash
# Run deterministic golden replay benchmark
pnpm aub:replay

# View latest summary report in terminal
pnpm aub:report

# Run benchmark test suite
pnpm test
```
